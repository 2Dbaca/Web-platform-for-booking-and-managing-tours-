Разработка веб-платформы для поиска, бронирования и управления
турами с разграничением прав доступа (гость, клиент, администратор).

Веб-сервер	Nginx
Контейнеризация	Docker, Docker Compose
Контроль версий	Git, GitHub


🚀 Установка и запуск
Способ 1: Запуск через Docker
bash
# Клонирование репозитория
git clone https://github.com/2Dbaca/Web-platform-for-booking-and-managing-tours-.git
cd tour-platform

# Запуск контейнеров
docker-compose up -d

# Остановка контейнеров
docker-compose down
Способ 2: Запуск через XAMPP
Скопировать папку проекта в C:\xampp\htdocs\tour-platform

Запустить Apache и MySQL в XAMPP Control Panel

Импортировать database.sql через phpMyAdmin

Открыть http://localhost/tour-platform
